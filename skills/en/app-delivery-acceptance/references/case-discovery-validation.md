# 已有用例查找质量回归

`tests/fixtures/case_discovery/suite.json` 冻结跨语言和类型的项目源码与场景；`expectations.json` 在模型工作区外保存独立预期与需要人工复核的语义标准。覆盖互补、参数/helper、误导性命名、弱断言、无匹配、完全无测试、真实跳过与未实现占位。它们是受控质量样例，不是宣称支持所有项目的证明，也不作为生产查找规则。

显式选择当前实际 Agent/模型后，可运行真实前向回归（产生模型调用；默认只读，不执行夹具业务测试）：

```sh
python3 <skill>/tests/run_case_discovery_forward.py --output /absolute/new-audit-directory
```

`--only <fixture-id> ...` 选择项目；`--mode debug` 另行验证原调试流程，须具备该项目自身的实际运行依赖，不自动安装系统运行器。每次使用新目录，保留回答、精确提示、绑定、引用、指标及失败。宿主只核对结构/引用和预期测试身份，不按关键词打分生成的语义说明；仍需独立阅读实际源码，复核漏找、误关联、边界夸大及可读性。修改后先用开发样例复测，再用未参与修改的独立保留项目验证；发现的问题保留历史记录，不能用手工重写回答代替重新调用。
