# DR-022：保留项目角色原始错误

## 状态

已接受，2026-10-31。

## 背景

原生 Windows 实测中，项目角色返回 error / workspace routing discovery timed out；指南把空答案继续当作 JSON 解析，metrics 只留下 Unexpected end of JSON input，掩盖了真实 Agent 错误。目录校验没有放宽，原记录保留。

## 决策

先保存角色原答并检查原始错误和终态，再解析成功的结构化答案。子进程失败向公开项目准备结果附带已保存的角色诊断。没有成功终态或完整答案不得发布指南；不由错误处理自动重放操作。

## 影响

Provider 路由等问题可以根据真实错误诊断；后续准备仍由总调度使用新不可覆盖请求决定。成功业务和权限、租约、快照合同保持不变。
