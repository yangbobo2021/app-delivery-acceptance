# DR-023：子流程接续失败的确定收尾

## 状态

已接受，2026-10-31。

## 背景

初次输入已经捕获调度失败，但暂停子流程回调后直接返回 plan，预算或原生角色错误会逃逸，留下已经完成子调用的任务归属。隔离协议回归复现了预算错误及遗留归属；并非 Windows 专有问题。

## 决策

接续采用与首次输入相同的失败收尾：保留原生原因、子回执及未知 pending，发布 blocked 消息结果，只释放当前 token 所有的任务锁。不匹配的回调继续拒绝；不修改预算，不自动重放子操作。

## 影响

已确认完成的子调用可由同任务的新授权消息继续；未知子效果仍由 pending 门禁阻止重放。无需 SPEX 内置测试业务规则。
