# DR-004: OpenCode 结构化结果交付

## 状态

已接受；依据用户要求修改现有测试 SKILL 并支持 OpenCode。

## 背景

真实 OpenCode 与 GLM 验证中，模型多次在要求的 JSON 之外添加说明，导致阶段结果解析失败。
仅依赖提示词不能稳定地交付机器结果。

## 决策

JSON 阶段显式请求 OpenCode 原生 JSON-schema 结果封装，并采用当前请求对应的已完成结构化对象。
运行时从原生事件流保留提交对象，按会话和请求身份关联后交给现有阶段门禁。
原始文字和工具事件保留；缺失结构化提交时阻塞，不从说明中抽取候选答案。
普通文本任务保持原有交付方式，其他 Agent 的结果流程不改变。

## 影响

现有结果字段、证据校验与独立复审要求继续有效。
改变运行时实现后创建新的模型尝试，不跨版本恢复旧会话。
