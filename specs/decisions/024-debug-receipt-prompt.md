# DR-024：调试证据的准确操作说明

## 状态

已接受，2026-10-31。

## 背景

Windows 实现角色完成了退出0的调试，随后反复查找分流日志并等待，最终角色超时。Prompt 错误要求 execution/stdout.log、stderr.log；实际入口仅生成 execution/execution.log 合并日志。原生 Node 工具探针可返回输出与退出码，不能把该问题归因于命令完全不能运行。

## 决策

仅纠正实现、查找及修复角色的操作说明：明确实际完成标记、退出回执及合并日志路径，observed 与已结束回执是本地执行完成；product_verdict:not_performed 是未作正式产品判定。缺少或不匹配证据仍失败，不通过反复等待不存在文件或重放已经结束的命令补造证据。

## 影响

不改执行器、断言、独立复审、目录门禁或租约。已发生超时及原始调试证据保留；新尝试仍需实际角色及正式流程核验。
